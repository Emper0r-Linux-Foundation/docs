# Welcome to Emperor Linux

**Rolling-release speed. Granular control. Built-in security.**

Emperor Linux is an early-stage, open-source Linux distribution developed by the Emper0r Linux Foundation. It is engineered around three core principles:

* **Up-to-date packages** — rolling-release availability of current software.
* **Zero-bloat, manual configuration** — minimal overhead and total system ownership.
* **Out-of-the-box defensive security** — built-in defensive utilities, built for reliable operation on any network.
