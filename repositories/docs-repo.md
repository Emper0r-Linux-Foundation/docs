# docs

**Repository:** [Emper0r-Linux-Foundation/docs](https://github.com/Emper0r-Linux-Foundation/docs)

## Purpose

The source of this documentation site.

## Contents

* `README.md` — the site's welcome page.
* `gitbook-docs.yaml` — the GitBook site configuration. It defines a single default space, `docs`, whose content is read from the repository root.

## How it is published

The repository is connected to the GitBook space through Git Sync. See [Contributing to the docs](../contributing.md).
