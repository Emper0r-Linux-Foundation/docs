# Contributing to the docs

## Where the docs live

The documentation source lives in the [docs](https://github.com/Emper0r-Linux-Foundation/docs) repository and is connected to this GitBook site through Git Sync. The `gitbook-docs.yaml` file at the repository root configures the site.

## Guidelines

* **One page per repository.** Each repository has a page under [Repositories](repositories/). Update it when the repository's behavior changes.
* **Document what exists.** Describe implemented behavior as fact. Put anything not yet built under a clearly labeled _Planned_ heading.
* **Remove the early-stage notice** from a repository page once the repository has real usage and build documentation.
* **Record decisions.** When a decision listed in the [Architecture overview](architecture-overview.md) is made, update both that page and the affected repository page.

## Suggested structure for a repository page

1. Purpose
2. Scope
3. Usage and build instructions (once available)
4. Open questions
5. Related repositories
